# Ticket System

## Описание
Данный проект представляет собой тикет-систему, разработанную с использованием C++ и Qt. Он включает функционал для обработки обращений пользователей, распределения тикетов, управления статусами и комментариями. Интерфейс приложения выполнен в современном стиле, напоминающем Angular 2.

## Структура проекта
- **src/** - Исходный код приложения
  - **main.cpp** - Точка входа в приложение
  - **controllers/** - Контроллеры для управления логикой приложения
    - **TicketController.cpp** - Реализация контроллера тикетов
    - **TicketController.h** - Объявление контроллера тикетов
  - **models/** - Модели данных
    - **Ticket.cpp** - Реализация модели тикета
    - **Ticket.h** - Объявление модели тикета
  - **views/** - Представления и интерфейсы
    - **MainWindow.ui** - Интерфейс главного окна
    - **MainWindow.cpp** - Реализация главного окна
    - **MainWindow.h** - Объявление главного окна
  - **utils/** - Утилиты и вспомогательные классы
    - **DatabaseManager.cpp** - Реализация менеджера базы данных
    - **DatabaseManager.h** - Объявление менеджера базы данных
  - **resources/** - Ресурсы приложения
    - **styles.qrc** - Ресурсы стилей

## Установка
1. Клонируйте репозиторий:
   ```
   git clone <URL>
   ```
2. Перейдите в директорию проекта:
   ```
   cd ticket-system
   ```
3. Соберите проект с помощью CMake:
   ```
   mkdir build
   cd build
   cmake ..
   make
   ```

## Использование
Запустите приложение, выполнив:
```
./ticket-system
```
